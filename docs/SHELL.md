# الهيكل الثابت لأقسام الموظفين (Shell)

ملفات: `management/shell/shell.js` + `shell.css`. بيتحمّل في: `/management/`، `/dashboard.html`، `/admin/staff.html`، `/erp/`، وكل صفحات `/QL/` (عن طريق `QL/rep-header.js` اللي بقى مجرد محمّل).

## بيعرض إيه
- **شريط علوي موحد:** لوجو، أقسام النظام (حسب `my_permissions()`)، بحث عن عميل، قائمة المستخدم (الاسم، الأدوار، **حسابي**، الخروج).
- **حسابي (`/management/account.html`):** صفحة واحدة لكل الموظفين (مش المناديب بس): تغيير الاسم الظاهر (دالة `update_my_profile` بتحدّث `staff_profiles` و`reps` معًا) وتغيير كلمة المرور بعد التحقق من الحالية. صفحة `QL/rep-settings.html` القديمة بقت تحويل لها.
- **تبويبات القسم:** داخل CRM (العملاء، المتابعات، سجل العروض، أداء المناديب) وداخل QL (أوف جريد، ري، عروض المنتجات، دراسة جدوى، الإعدادات).
- **بانر الصفحات مضغوط:** عنوان الصفحة بس (اللوجو والروابط في الشريط).

## القسم بيتحدد تلقائيًا من المسار
`/management*` ← الرئيسية · `/QL/rep-customers|rep-crm` ← العملاء (CRM) · باقي `/QL/*` ← عروض الأسعار · `/dashboard.html` ← لوحة التحكم · `/admin/staff*` ← الموظفين · `/erp*` ← ERP.

## إضافة قسم أو تبويب
- **قسم جديد:** أضف عنصر في `SECTIONS` + سطر في `detectSection()` + صلاحيته، وأضف سطري التحميل (`shell.css` و`shell.js`) في صفحاته. بطاقته في `/management/` بتتضاف في مصفوفة `GROUPS` هناك.
- **تبويب جديد:** عنصر في `SUBNAV[<القسم>]` (`key` = `اسم-الملف|#hash`).

## قواعد
- الإظهار/الإخفاء تجميل؛ الحماية الفعلية RLS ودوال السيرفر.
- كل نص من قاعدة البيانات بيتحط بـ `textContent` (بدون `innerHTML`).
- البحث بيشيل أي حرف غير (حروف/أرقام/مسافة/+/-/.) قبل ما يتبعت كفلتر.
- لوحة «اليوم» في `/management/` من دالة `crm_today_summary()` (بتحترم الصلاحيات؛ لا تكلفة ولا ربح).
- الطباعة: الشريط مخفي (`@media print`).
