# خطة اختبار يدوية (بعد أي رفع)

كل الاختبارات الآلية اللي اتعملت كانت على قاعدة البيانات أو بمحاكاة. دي الاختبارات اللي لازم تتعمل على متصفح حقيقي.

## تجهيز
أنشئ 3 مستخدمين تجريبيين من `/admin/staff.html`: `t.admin` (أدمن)، `t.manager` (مدير مناديب)، `t.rep` (مندوب). احذفهم/عطّلهم بعد الاختبار.

## 1) السوبر أدمن (حسابك)
- [ ] `/dashboard.html`: كل الأقسام ظاهرة + «إدارة الموظفين» + «ERP (قيد التجهيز)».
- [ ] `/admin/staff.html`: إنشاء مستخدم، تغيير باسورد، تعطيل/تفعيل، تعديل أدوار.
- [ ] `/QL/rep-customers.html`: جدول أداء المناديب يظهر.

## 2) الأدمن `t.admin`
- [ ] دخول `/dashboard.html` بالـ username.
- [ ] يظهر: المقالات، المشاريع، الأسئلة الشائعة، طلبات العملاء، المنتجات، شعارات الماركات. **لا** يظهر: الحاسبات، خصومات الموردين، المناديب، إدارة الموظفين.
- [ ] إضافة مقال ونشره ✔، إضافة منتج ✔.
- [ ] الصفحة الرئيسية للوحة بدون أخطاء حمراء (احتمال ظهور بيانات فاضية في بعض الإحصائيات — سجّلها).
- [ ] `/QL/` ← يُرفض (لحد ما تضغط «فتح QL»).
- [ ] بعد «فتح QL»: يدخل `/QL/`، يصدر عرض سعر، ويشوف عملاءه.
- [ ] بعد «غلق QL»: يُرفض تاني.

## 3) مدير المناديب `t.manager`
- [ ] دخول `/QL/` ← CRM: يشوف عروض كل المناديب + لوحة النشاط.
- [ ] `/QL/rep-customers.html`: جدول الأداء، إسناد عميل لمندوب، إضافة متابعة.
- [ ] لا يشوف التكلفة والربح.

## 4) المندوب `t.rep`
- [ ] دخول `/QL/` بالـ username، تقديم عرض سعر.
- [ ] `/QL/rep-customers.html`: عملاؤه فقط، بدون جدول الأداء وبدون صندوق «إسناد».
- [ ] تغيير حالة عرض، تسجيل مكالمة، إضافة متابعة، «تم» على متابعة.
- [ ] تغيير الباسورد من الإعدادات (يرفض أقل من 10).
- [ ] إيقاف الأوف جريد من الـ dashboard ثم محاولة عرض أوف جريد ← يُرفض.

## 5) عام
- [ ] زائر بدون تسجيل: الموقع والحاسبات والمنتجات والمقالات شغالة.
- [ ] زر «CRM» في الـ dashboard يفتح `QL/rep-crm.html`.
- [ ] `/erp/` تعرض «قيد التجهيز».
