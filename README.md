# Al Asl Solar Website

Static GitHub Pages website for Al Asl Solar.

## Test locally

Open `index.html` in a browser, or serve the folder with any static web server.

## Pages

- `index.html`
- `about.html`
- `services.html`
- `projects.html`
- `articles.html`
- `contact.html`
- `admin/index.html`
- `dashboard.html`

## Content editing

Projects and articles can be added from `dashboard.html` using Supabase Auth, Database, and Storage.

Run `supabase-setup.sql` once in Supabase SQL Editor. It is configured for `REDACTED`. Then create that user in Supabase Authentication with an email/password.
